# Jarvis Idiomas

Tradutor e dicionario por voz - Portugues, Ingles, Espanhol e Coreano.

App web gratuito (funciona no navegador, sem instalar nada):
segura o botao de microfone (ou digita), fala/escreve a palavra ou
frase, e ele traduz e fala a resposta de volta.

Funciona no PC e no celular. Pra usar no dia a dia no celular, abra o
link e escolha "Adicionar a tela de inicio" no navegador.
